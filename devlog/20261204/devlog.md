# Lore Dumpster of SPLORR!! demo is on itch.io

*Draft for December 4, 2026 (not for the post: this line). Post type: Major update or launch. For the picture, use itch's hosted copy of the cover or the `06-kitchen.png` screenshot once the page has it. Not approved by the user yet.*

Lore Dumpster of SPLORR!! has been playable on GitHub Pages since November 24. Today the demo gets a page here too.

It's a turn-based puzzle adventure in four colours, the way the TRS-80 Color Computer drew them. The Investors of SPLORR!! bought the other twelve colours, and you're going down the vault to get them back.

- **10 levels:** one room each, the first block of the vault.
- **Traps on fixed cycles:** spikes, arrows, fire jets, crushers, boulders, pits. Watch, then move.
- **Secrets:** fake walls, cracked walls and a hidden gem in most levels.
- **Lore:** a page of it before every level, whether you want it or not.

This is a demo. More levels (and the shop, the checkpoints and the bonus level) get built only if people find it interesting, so if you play it, press F in the game to send feedback or leave a comment here.

The latest version always lives at https://playdeezgames.github.io/lore-dumpster-of-splorr/ and the itch build can lag behind it.
